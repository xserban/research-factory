## Rulings made in this plan

1. **Old LaTeXML conversions stay.** Conversions are immutable records; the bump to `CONVERTER_VERSION = "1.2"` makes `document convert` produce a new conversion for each LaTeXML-converted document (it already treats a differing `converter_version` as a new key, `document_convert.py` ~229). Extraction tasks pin `(document_id, conversion_id)`, so existing extraction rows keep their old pin and verify against the old text; nothing is staled automatically (a new conversion of the same document only raises a `check` warning, plan D ruling 5). Cost if wrong: a researcher must re-extract affected works by hand. Recorded as a *Proposed* decision (Task 5). **[confirm]**
2. **Abandoned tasks are reported, not hidden.** `TaskCounts` gains `abandoned` (default 0); `open` stops counting extraction tasks replaced by a newer task of their unit. `events_by_type` is unchanged.
3. **No new `AuditReport` data source.** Per-work evidence is read from `audit_items` only (work, agreed verdict, criteria, human verdict); quotes and anchors of full-text decisions are not copied into the report.

## Review Focus

1. A LaTeXML paragraph whose text contains `*`, `_`, a backtick or `~~` renders as literal text, not as emphasis or code, and the manifest's quotes still verify against it (Task 5).
2. An anchor id with a trailing newline (`"s1\n"`) is refused by the manifest check (Task 3).
3. Paging a 20 000-anchor manifest to the end costs linear, not quadratic, work, and returns the same segments as before (Task 4).
4. After a document version change re-queues a unit, `project_status` shows the old task as abandoned and the new one as open; completing the new task leaves `abandoned` at 1, not `open` at 1 (Task 6).
5. An audit report with no human labels still lists its sampled works; a held-out or unsampled work never appears (Task 7).

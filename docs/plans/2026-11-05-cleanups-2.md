## Rulings made in this plan
1. **Chase gate unchanged. [confirm]** Task 2 changes how a chase query is *linked* to its round (by ref), not how it is *authorised*: the waiver for texts of a recorded `search_chase` round stays as it is, so old runs remain resumable. Tightening the waiver to "only a query naming its round" (as for snowball rounds, slice-3a) would refuse an agent's hand-registered chase text and is a separate decision. Cost if wrong: one loophole stays open until that decision.
2. **Legacy link fallback. [confirm]** A chase query whose `query.registered` refs name no round is linked by the current text rule (latest earlier round with the same text). New queries always carry the ref, so the fallback serves old logs only; trace output for old logs is unchanged.
3. **Repeat seed explanation is refused. [confirm]** Today the projector keeps the first `seed.miss_explained` and silently drops later ones, so a correction is accepted and then ignored. Until correction by supersession is specified, `explain_seed_miss` refuses a seed already explained (`seed_id: already explained`), writing nothing. Cost if wrong: the researcher cannot correct an explanation (as today, but now told so).
4. **Unqueried snowball round. [confirm]** A recorded snowball round with no registered query (every registration refused after `snowball.round_started`) counts like a round with failed runs: the no-yield stop does not apply to its successor (slice-3a ruling 6: the rule stops on a round that *yielded* nothing, and an unqueried round did not run).

## Risks & mitigations

- **Sticky canvas overlap with hub `.topbar`**: The hub `.topbar` is `position: sticky; top: 0; z-index: 20`. Measure `.topbar` height dynamically into `--ov-top-h` and keep `.ov-stage-sticky` below it with lower `z-index` than topbar/drawer/popovers.
- **Digits-in-template static test (`test_hub_ui_pages.py`)**: Template literals mentioning `paper(s)`/`record(s)`/`work(s)` must never contain literal digits `2–9` or multi-digit numbers (such as `2025`, `2026`, `06`). Compute or interpolate all numbers dynamically.
- **Small / empty fixtures in tests**: Test worlds may have only 3–10 included papers, 0 coded human roles, 0 months, or `not_run` full-text stages. Guard every layout division, `sampleNumberDots`, and year comparison so small or empty corpora render cleanly with zero JS errors.
- **LCARS / light / gruvbox contrast on canvas**: Read all colours through `H.cssv(...)` via a 1×1 probe canvas on init and on every `hub:theme` event, and verify visually at 1440 px and 390 px across `dark`, `light`, `gruvbox`, and `lcars`.

# Lane L2-brief-tier: tier plans and the brief tier

First read `_common.md` in this folder, then the plan.

Implement contract item C3 (branch `tiers/L2-brief-tier`). (1) `factory/tiers/` per C3 with typed plans for `brief`, `deep`, `pilot`, `systematic`: for `pilot` and `systematic` the plan names today's stages in order with no caps (derive stage ids from `site_catalog.STAGE_IDS`); for `brief`: frame-lite (question, optional seeds, exploratory protocol template; the protocol gate is off in exploratory), gather (at most 2 sources, one search per source, dedup, no snowball), screen (one pass, ranked with the stopping rule: see `services/ranking.py`, `ranked_queue.py`; at most 40 screened), acquire (open access only, at most 20 included), extract (a template schema of at most 6 fields, one pass), write (an evidence note from `report_evidence` plus verified quotes via `chat_verify`/claims digest, and the level statement), limits `Limits(max_papers=30, max_minutes=60, max_runs=12)`; for `deep`: brief plus protocol-lite with an independent PRESS-lite review (a separate session), at most 3 sources, one capped snowball round, a sampled audit, the contradiction finder, agreement on a sample, limits `(150, 360, 60)`. `skipped_steps(tier)` is computed by diffing the plan's stage list against `systematic`'s. Protocol and report templates are data (find the format of the existing protocol sections in `model/protocol.py` and the extraction schema format; keep them valid: add a test that builds a project from the brief template through the normal protocol service). (2) Skill `plugin/skills/rf-brief/SKILL.md` (frontmatter `stage` as the other skills, a guided procedure that names only existing tools and commands: verify each against `mcp/server.py` and the typer app; the label 'quick review, skipped: ...' in the note; human gates marked) and `cli/brief.py`: `factory brief new "<question>" [--slug]` creates an exploratory project with tier brief (use the init service with the `tier` parameter when L1 is merged; until then call the init service with mode exploratory and record the tier in your report as pending), `factory brief plan <project>` lists the plan and limits, `factory brief status <project>`. Tests: plan data (every tier, skipped steps computed), the template validity test, the CLI plan listing, `test_plugin.py` pin for the skill (run once), `test_learn_content.py` if you touch learn data (run once).
